# CONNECT Guidelines for Agents

## UI Design & Aesthetic Constraints
- **NO AI Badges / Generic Pill Tags**:
  - Never add artificial pill badges/tags such as `RECIBIDO`, `Conectado a Firebase`, or colored pill buttons like `Mover a Papelera`.
  - Maintain the sleek, professional, and authentic CONNECT design system (subtle borders, refined neutral typography, clean icon action buttons, consistent spacing).
  - Do not add artificial "AI-looking" status pills or decorative badges neither on the web admin panel nor inside the Flutter mobile app.
